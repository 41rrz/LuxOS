# Upgrade LuxOS 0.2.x to 0.3

Copy the files in the 0.3 patch over the matching files in your existing LuxOS repository.

Changed files:

- `src/App.tsx`
- `src/styles.css`
- `src/apps/AppContent.tsx`
- `src/system/types.ts`
- `src/system/storage.ts`
- `package.json`

Then run:

```powershell
npm install
npm run build
```

`npm install` will keep your dependency lockfile aligned with the 0.3 package metadata. Commit both `package.json` and any resulting `package-lock.json` change.

Suggested commit message:

```text
Build LuxOS Desktop v0.3 interaction overhaul
```

## New controls

- Drag a window to the left/right edge to snap it.
- Drag a window to the top edge to maximize it.
- Hold `Alt` and press `Tab` to switch between open windows.
- Hover a running taskbar app to see its preview.
- Drag desktop shortcuts anywhere on the desktop; positions are saved.
- Drag an empty area of the desktop to create a selection rectangle.
- Click the network or volume icons in the system tray for flyouts.
- Open Personalize to switch between Aurora, Midnight and Afterglow wallpapers.
