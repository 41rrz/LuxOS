# Changelog

## 1.0.0 Mega Update

- Desktop-backed virtual filesystem integration.
- Recycle Bin and restore/permanent-delete workflows.
- Copy/cut/paste, multi-select and keyboard file operations.
- Multi-instance window manager and taskbar grouping.
- Start menu program + file search.
- File associations and dedicated Photo Viewer.
- Lux Paint, Calculator and Media Player.
- Expanded Terminal filesystem commands.
- Account image/name personalization.
- Desktop icon sizing and taskbar clock seconds.
- Refined Aero/Lux glass and utility-app styling.

## 0.4.0

- Persistent virtual filesystem preview.
- Gallery imports, Notes storage, custom wallpapers, Aero Peek and notifications.
- Hybrid IndexedDB asset storage for larger image/audio imports while preserving synchronous VFS metadata.
