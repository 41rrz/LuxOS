# LuxOS Changelog

## 0.3.0

### Desktop interaction
- Added left/right/maximize window snapping with live snap preview.
- Added Alt+Tab window switcher.
- Added taskbar hover thumbnails and close actions.
- Improved taskbar behavior so inactive windows focus before minimizing.
- Added draggable desktop shortcuts and persistent icon placement.
- Added a Windows-style desktop selection rectangle.
- Added persistent window sizes and positions.

### System tray
- Added network flyout.
- Added master-volume flyout and sound test.
- Added optional synthesized LuxOS session/interface sounds.

### Personalization
- Added Aurora, Midnight and Afterglow wallpapers.
- Added wallpaper picker to Personalize.
- Added custom LuxOS cursor.
- Improved glass, reflections, boot/login animation and desktop depth.

### Reliability
- Includes the 0.2.1 calendar TypeScript fix.
