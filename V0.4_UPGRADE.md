# Upgrade LuxOS Desktop 0.3 → 0.4

Use this patch on top of the existing LuxOS 0.3 repository.

## Replace these files

- `src/App.tsx`
- `src/apps/AppContent.tsx`
- `src/styles.css`
- `src/system/storage.ts`
- `src/system/types.ts`
- `public/sw.js`
- `package.json`
- `README.md`
- `CHANGELOG.md`

## Add this file

- `src/system/vfs.ts`

## Keep these files

Keep your existing `package-lock.json`, `.github/workflows/deploy-pages.yml`, `vite.config.ts`, `index.html`, `src/main.tsx`, icons and other project files. LuxOS 0.4 uses the same npm dependency set as 0.3.

## Test before pushing

```powershell
npm install
npm run build
npm run dev
```

Then test these interactions:

1. Sign in and open Computer.
2. Create a folder and a text document.
3. Edit and save the text document.
4. Import an image and confirm it appears in Gallery.
5. Open Terminal and try `dir`, `cd Documents`, `type Welcome.txt`, `mkdir Test`, and `touch hello.txt`.
6. Hover the thin Show Desktop strip at the far-right of the taskbar for Aero Peek.
7. Drag pinned taskbar icons to reorder them and refresh the page to verify the order persists.
8. Open Personalize and upload a custom wallpaper.
9. Open the notification tray.
